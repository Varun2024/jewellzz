# Jewelzz

Internal desktop app for jewellery shop transactions and management. Single-PC, offline-first. Stack TBD.

See [`PRD.md`](./PRD.md) for the prototype product spec.

## Raw requirements (verbatim, source of truth)

> inventory, cash ledger, metal ledger, party ledger, sale, challan sale, purchase, challan purchase, unregistered purchase, approval receive and issue, repair, order, karigar management, metal refining, gst reports, e-way bills, cataloging, inventory tagging, bill format, data backup, multiple companies
